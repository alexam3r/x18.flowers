# x18.flowers — инструкции для Claude Code

Прошивка ESP32-C3 SuperMini для пяти LED-полок цветочного стеллажа.
Управление по MQTT из Home Assistant / Яндекс Умного Дома.

   работы: архитектура, принятые решения, ограничения, чек-лист приёмки.

## Быстрые команды

```bash
cp include/Secrets.h.example include/Secrets.h   # если файла нет
pio run
pio test -e native
pio run -t upload
pio device monitor -b 115200
```

## Нельзя

- Коммитить `include/Secrets.h`, `.pio/`, `.pio-core/`, `.dsh/`, `.remember/`.
- Менять пины `{0,1,3,4,10}`, ШИМ 4000 Гц / 12 бит.
- Публиковать состояние полки в `panel_N`: `panel_N` — только команда,
  состояние — в `panel_N_state`.
- Хардкодить IP MQTT-брокера: только `WiFi.gatewayIP()`.

## Правила

- Тег `v1.0.0` — неизменяемый baseline. Новые доработки — только по явному
  запросу, в отдельной ветке, с проверкой изменений на железе.
- Коммиты — на русском языке, с описанием сделанного.
- При изменении прошивки обновлять `README.md`.
- Перед коммитом: `pio run` и `pio test -e native`.
- После изменения: `graphify update .`, commit, push, проверка на железе.
